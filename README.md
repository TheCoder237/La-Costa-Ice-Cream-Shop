# La Costa Ice Cream Shop Website

A responsive website built for a real local business, La Costa Ice Cream Shop in Millington, Tennessee.

The site is designed to help customers view the menu, see featured products, call ahead to place an order, find the shop, view business hours, and access the shop's social media pages.

## Current Features

- Responsive design for desktop and mobile
- Homepage with featured products
- Menu featuring ice cream and Mexican treats
- Full bilingual-friendly menu
- Call-to-order functionality
- Business hours and location
- Google Maps directions
- Facebook and Instagram links
- Contact page
- SEO meta descriptions
- Custom favicon

## Technologies Used

- HTML5
- CSS3
- Responsive Web Design
- CSS Grid
- Flexbox
- Git and GitHub
- GitHub Pages

This project was created as a real-world web development project for La Costa Ice Cream Shop.

The goal is to create a simple, mobile-friendly website that makes it easier for customers to discover the business, browse the menu, call ahead or order through DoorDash, and find the shop.
